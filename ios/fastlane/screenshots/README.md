# App Store Screenshots

These screenshots are prepared for the Kotrana public App Store submission.

- Locale: `en-US`
- Device classes:
  - iPhone 6.9-inch portrait, `1290 x 2796`
  - Apple Watch 45 mm portrait, `396 x 484`
- Source captures: existing app screenshots under `/screenshots`
  - Apple Watch capture: prepared from the current watchOS active-workout UI

Apple accepts `1290 x 2796` as a portrait screenshot size for the 6.9-inch iPhone display class and `396 x 484` for Apple Watch 45 mm. Upload these manually in App Store Connect, or use Fastlane once the App Store Connect API key has permission to edit metadata/screenshots.
