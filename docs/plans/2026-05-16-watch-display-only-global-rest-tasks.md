# Watch Display-Only Global Rest Tasks

## Goal

Turn the Watch app into a read-only workout companion and make rest timing global
across all Watch pages.

## Tasks

- [x] Add a session-level active rest payload to Watch snapshots.
- [x] Make Watch-originated log events ignored by the phone app.
- [x] Move rest haptic ownership out of exercise pages and into the Watch session manager.
- [x] Show workout duration persistently on Watch exercise pages.
- [x] Show the same active rest countdown on every Watch exercise page.
- [x] Remove Watch UI controls that mutate workout data.
- [x] Enable Watch workout background mode for more reliable active-workout execution.
- [x] Verify with focused Watch sync tests, static iOS project tests, analysis, and a paired simulator build.
